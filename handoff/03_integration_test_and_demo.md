## 5. แก้ปัญหา (อาการ → สาเหตุ → แก้)

| อาการ | สาเหตุที่น่าจะเป็น | แก้ |
|---|---|---|
| "เชื่อมต่อระบบไม่ได้ · ยังไม่ได้ตั้งค่าที่อยู่ระบบ (API_BASE)" | `config.js` ยังว่าง | มิ้นใส่ `API_BASE` → deploy |
| "เชื่อมต่อระบบไม่ได้" เฉย ๆ (ไม่มีรายละเอียด) | tunnel ล่ม / URL ผิด / ช้าเกิน 8 วิ / CORS | เปิด `$API/health` ในมือถือ · เปิด Console (F12) ดูว่ามีคำว่า CORS ไหม → ธรเช็ก `CORS_ORIGINS` |
| "ต้องเข้าผ่าน LINE" | backend ตั้ง `LIFF_CHANNEL_ID` แล้ว แต่หน้าเว็บยังไม่มี `LIFF_ID` หรือเปิดลิงก์ vercel ตรง ๆ แทน `liff.line.me` | ใส่ `LIFF_ID` / เปิดผ่าน `https://liff.line.me/<LIFF_ID>` |
| "ยืนยันตัวตนไม่ผ่าน" | `LIFF_CHANNEL_ID` ไม่ใช่ channel ที่มี LIFF นี้ / ไม่ได้เปิด scope `openid` | กาฟิวเช็ก Channel ID และ scope |
| ทุกคนเห็นล็อตเดียวกัน | backend ยังไม่ตั้ง `LIFF_CHANNEL_ID` (ทุกคนเป็น `dev-user`) | ตั้งแล้ว restart |
| Push ไม่มา | ไม่ได้แอดเพื่อน OA / token ผิด / ผู้ใช้เป็น `dev-…` / คนละ Provider / โควตาหมด | `curl $API/debug/pushes` ดูว่าส่งจริงไหม · `journalctl -u tgr49 -f` ดู "Push ไม่สำเร็จ" |
| ปุ่มใน Push เปิดหน้าแปลก (หน้า JSON / หน้า backend) | backend ไม่มี `LIFF_ID` → ลิงก์ไป `PUBLIC_BASE_URL` | ธรตั้ง `LIFF_ID` (หรือแก้ `liff_url` ตาม `01` ข้อ 6) |
| ปุ่มใน Push เปิดแอปแต่ไม่ใช่ล็อตนั้น | ล็อตถูกลบ (รีเซ็ต) → 404 → แอปกลับไปล็อตล่าสุดเอง | ปกติ ถ้าไม่ใช่กรณีนี้แจ้งมิ้น |
| "ล็อตนี้ไม่ใช่ของคุณ" | เปิดลิงก์ `?lot=` ของคนอื่น | ปกติ (403) |
| ภาพเมล็ดไม่ขึ้น (เห็นไอคอนเมล็ดแทน) | `vis_url` เป็น http/localhost | ธรตั้ง `PUBLIC_BASE_URL` = URL https ของ tunnel |
| ปุ่มเดโมขึ้น "ต้องใส่ X-Demo-Key" | คีย์ผิด / ธรเปลี่ยนคีย์ | กดใหม่แล้วใส่คีย์ที่ถูก |
| รีเซ็ตด้วย curl แล้วหน้าเว็บไม่เปลี่ยน | curl ใช้ `X-Dev-User: user` (= `dev-user`) แต่หน้าเว็บเป็น `dev-dev` · หรือเปิด LINE แล้ว (ผู้ใช้จริง) | ใช้ `X-Dev-User: dev` · หรือรีเซ็ตจากแถบเดโมในแอป |
| แก้หน้าเว็บแล้วมือถือยังเห็นของเก่า | ยังไม่ได้ deploy / LINE จำหน้าเดิม | มิ้น deploy · ปิดหน้าแอปใน LINE แล้วเปิดใหม่ |
| หน้าแอปค้างกล่องเทา | JS error | เปิดในคอม F12 → Console ส่งข้อความ error ให้มิ้น |

## 6. Freeze ก่อนนำเสนอ
1. ทดสอบรอบ B ผ่าน 3 รอบติด (อย่างน้อย 1 รอบบน Android และ 1 รอบบน iPhone)
2. มิ้น: merge `web-liff` → `main` · `git tag v1.0` · deploy ครั้งสุดท้าย
3. ธร: tag backend v1.0 · ไม่แก้ `.env` อีก
4. กาฟิว: channel → Published · QR · Rich menu · อัดวิดีโอสำรอง
5. เช้าวันนำเสนอ: C5 ใน `03_กาฟิว_LINE_และเดโม.md` + เปิด https://tgr49-liff.vercel.app/?mock=ready ในมือถือสำรองไว้หนึ่งแท็บ
