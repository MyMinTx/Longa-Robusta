## 4. หน้าเว็บเรียก backend อย่างไร

`API_BASE` + path · timeout 8 วินาที · ทุก request ส่ง header:
- `Content-Type: application/json`
- `Authorization: Bearer <liff.getIDToken()>` เมื่อ LIFF พร้อม
- ไม่มี token (ยังไม่ตั้ง LIFF_ID หรือ LIFF init ไม่ผ่าน) → ส่ง `X-Dev-User: dev` แทน → backend โหมดพัฒนาจะมองเป็นผู้ใช้ **`dev-dev`**
- ปุ่มเดโมส่ง `X-Demo-Key` เพิ่ม

| Method | Path | เมื่อ |
|---|---|---|
| GET | `/lots/latest` | เปิดแอปไม่มี `?lot=` |
| GET | `/lots/{lot_id}` | มี `?lot=` · และทุกครั้งที่ดึงข้อมูลใหม่หลังรู้ lot_id แล้ว |
| POST | `/lots/{lot_id}/sell` | ปุ่มยืนยันขายใน sheet 06 |
| POST | `/lots/{lot_id}/inspect` (`?improved=true` เมื่อ `?demo=1`) | ปุ่มขอตรวจใหม่ (หน้า 09) |
| POST | `/lots` | ปุ่มเริ่มล็อตใหม่ (หน้า 08) |
| POST | `/demo/reset` | ปุ่มรีเซ็ต (แถบเดโม) — มีกล่องยืนยันก่อน |
| POST | `/demo/speed` body `{"moisture_tick_seconds":2,"market_round_seconds":2}` / `{…30, …10}` | ปุ่มเร่งเวลา / ปกติ |

**ไม่ได้ใช้** `/lots/{id}/events?since_id=` — หน้ากำลังขายดึง Lot ทั้งก้อนทุก 5 วิแทน (ง่ายกว่าและ events อยู่ใน Lot แล้ว)

### จังหวะดึงข้อมูล
- ทุก 10 วินาที · หน้ากำลังขาย (`SELLING`) ทุก 5 วินาที
- หยุดดึงเมื่อแอปไปอยู่เบื้องหลัง · ดึงทันทีเมื่อกลับมาหน้าจอ
- วาดหน้าใหม่เฉพาะเมื่อข้อมูลเปลี่ยน / เน็ตกลับมา / เวลาผ่านไปจนข้ามเกณฑ์ 30 นาที

### การจัดการ error
| code | แอปทำอะไร |
|---|---|
| 401 | นอกแอป LINE → `liff.login()` · ในแอป LINE → โหลดหน้าใหม่ 1 ครั้งเพื่อขอ token ใหม่ · ถ้า LIFF ยังไม่พร้อม → แสดงข้อความจาก backend (เช่น "ต้องเข้าผ่าน LINE") |
| 403 | แสดง `detail` |
| 404 | ไม่พบล็อต (เช่น `?lot=` ของล็อตที่ถูกรีเซ็ตไปแล้ว) → ทิ้ง lot_id แล้วเรียก `/lots/latest` |
| 409 / 423 ตอนกดขาย/ขอตรวจใหม่ | ปิด sheet · แสดง `detail` · ดึงล็อตใหม่แล้ววาดใหม่ |
| เน็ตหลุด / timeout / 5xx | มีข้อมูลเดิม → หน้าแบบ 10 "เชื่อมต่อระบบไม่ได้" · ไม่มี → หน้าเชื่อมต่อไม่ได้ · ใน sheet ขาย → กล่องแดง "ยังไม่ได้ขาย ลองกดอีกครั้ง" |

ปุ่มที่ส่ง POST ทุกปุ่ม: ระหว่างส่งปิดปุ่ม + ขึ้น "กำลังส่ง…" และส่งได้ทีละครั้ง (กดรัว 5 ครั้ง = ส่ง 1 ครั้ง ทดสอบแล้ว)

## 8. แก้ค่า / deploy ใหม่
1. แก้ `web/config.js`
   ```js
   window.APP_CONFIG = {
     API_BASE: "https://<เครื่อง>.<tailnet>.ts.net",   // ไม่มี / ท้าย
     LIFF_ID: "2000000000-AbCdEfGh",
   };
   ```
2. deploy (เครื่องมิ้นที่ล็อกอิน Vercel แล้ว)
   ```powershell
   cd <repo>\web
   npx vercel deploy --prod
   ```
3. เปิดเช็ก https://tgr49-liff.vercel.app (Vercel ตั้งให้เบราว์เซอร์ไม่จำไฟล์เก่า เห็นของใหม่ทันที)

ถ้าธรหรือกาฟิวต้องแก้หน้าเว็บเอง: แก้ใน branch `web-liff` แล้ว push → บอกมิ้นให้ deploy
(หรือมิ้นเชื่อมโปรเจกต์ Vercel กับ GitHub: Vercel → tgr49-liff → Settings → Git → เลือก repo · Root Directory = `web` · จากนั้น push เข้า production branch แล้ว deploy เอง)
