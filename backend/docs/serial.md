# ESP32 → Pi ผ่าน USB Serial (ข้อ 0.06) — ให้เฟิร์สยืนยัน

ตามกติกา Track 1 ข้อ 3.2–3.5:

- Baud rate **9600**
- ส่งค่าเมื่อ **กดปุ่ม 1 ครั้ง** เท่านั้น (ไม่ส่งเองเป็นระยะ) → ช่วง "กำลังตาก" จริงต้องมีคนกดปุ่ม หรือใช้โหมดเร่งเวลาตอนเดโม
- รูปแบบ (ทศนิยม 2 ตำแหน่ง แล้วเว้น 1 บรรทัด):
  ```
  "TGR-49" Moisture Level = 11.55 %

  ```
- **ห้ามแก้เฟิร์มแวร์แข่งเพื่องานนี้** และห้ามเปิด Wi-Fi ในเฟิร์มแวร์แข่ง
- หลัง 20 พ.ย. 11:00 เครื่องอยู่กับกรรมการ

## สิ่งที่ต้องเช็กบน Pi
1. เสียบ ESP32 แล้วรัน `ls /dev/ttyUSB* /dev/ttyACM*` → จดชื่อพอร์ตลงชีต "ค่าตั้งค่า"
2. `sudo usermod -aG dialout $USER` แล้ว logout/login (ไม่งั้นเปิดพอร์ตไม่ได้)
3. ทดสอบ: `python3 api/serial_reader.py /dev/ttyUSB0` แล้วกดปุ่ม ต้องเห็นค่าขึ้น
